# ABSENSI-NEUR

Platform HR & absensi GPS berbasis Next.js (HadiR).

## Stack

- Next.js 15 + React 19
- Tailwind CSS v4
- Recharts

## Menjalankan lokal

```bash
npm install
npm run dev
```

Aplikasi berjalan di `http://localhost:8443`.
